## About

This repository contains my notes, key concepts, practical techniques, and lab experience while progressing through the PortSwigger Web Security Academy.

The goal is not only to complete the labs, but to understand how web vulnerabilities work, how they can be identified and exploited, and how to approach them from a penetration tester's perspective.
