# API Testing

## Overview

This learning path focuses on testing APIs that are not fully used or exposed through the website's front-end.

The main goal is to learn how to discover API endpoints, understand how they work, identify unintended functionality, and test APIs for vulnerabilities that may expose additional attack surface.

The learning path covered:

- Identifying and interacting with API endpoints
- API documentation
- HTTP methods and the OPTIONS method
- Finding unused API endpoints
- Mass assignment vulnerabilities
- Server-side parameter pollution
- Query string pollution
- REST path pollution
- Structured data format pollution
- Automated tools for detecting suspicious input transformations
